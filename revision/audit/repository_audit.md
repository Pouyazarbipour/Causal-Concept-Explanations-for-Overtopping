# Repository audit (Phase I)

Written before any original file was changed. The state that was audited is
commit `a76c2dd` (see `original/ORIGINAL_COMMIT.txt`).

**Snapshot.** A copy of the original code, results and manuscript is kept in `original/`:
- `original/original_code` — `src/`, `experiments/`, `configs/`, `tests/`, `run_all.py`;
- `original/original_results` — `tables/`, `reports/`, `predictions/`, Optuna output;

Every new module has a new file name. No original script, table, figure or prediction was overwritten.

## 3. Problems found

| # | Problem | Consequence | Status |
|---|---|---|---|
| A1 | Table 2 reports the mean of the five fold-wise RMSEs; Table 4 reports the pooled out-of-fold RMSE. For the MLP, Table 2 also uses the seed ensemble while Table 4 uses the mean of per-seed values (0.547 vs 0.576) | the two tables do not agree; neither is wrong, but the definitions differ | fixed in the revision: pooled OOF RMSE everywhere, fold-mean labelled as such in the SI |
| A2 | "143 tests with unusable inputs" is mislabelled. The 143 are all records outside the wet/dry set: 21 with an invalid response plus 122 with unusable inputs and a valid response. In total 123 records have unusable inputs, one of which also has an invalid response. All 143 are RF = 4 | wrong label in the text | corrected |
| A3 | "32 geometries (311 tests) with more than one CF" and "RF varies within 166 geometries" refer to ALL 10 532 records (2 209 geometries). The text sets them beside the regression set (2 046 geometries), where the counts are 27 / 283 / 140 | population not stated | corrected |
| A4 | The CF = 3 "geometry RMSE 0.391" is an unweighted mean of per-geometry RMSEs over 263 geometries with max CF = 3 (935 tests). The record-level CF = 3 RMSE of 0.71 is pooled over 825 tests with CF = 3. Both are correct but they use different units and populations. Series 506 (over-prediction > 2 log10 units) carries a large share of the record-level error | the two numbers look contradictory | explained in the revised text and in `numerical_consistency_audit.csv` |
| A5 | P6a/P6b/P6c: the variance model σ²(RF, CF) that scales the intervals was fitted to inner out-of-fold residuals of the whole outer-training partition, *including the calibration geometries* | weak violation of score-function independence in split conformal | v2 fits it on proper-training geometries only (`src/counterfactual_policies.py`, `src/conformal_uncertainty.py`); v1 kept for comparison |
| A6 | Conformal intervals reuse hyper-parameters tuned on the whole outer-training partition, including the calibration geometries. The mean model itself is fitted on proper-training rows only | mild dependence through hyper-parameter choice | documented as a limitation; not changed (re-tuning per calibration split is computationally prohibitive) |
| A7 | The original wet/dry model has fixed hyper-parameters and its own GroupKFold, not the regression folds. It has no threshold, calibration or confusion analysis | incomplete | new nested two-stage model (`src/wet_dry_model.py`); original kept |
| A8 | Cross-references in the draft: the REML section cites "Fig. 4" (it is Fig. 5); the policy section cites "Fig. 5" and "Fig. 6" (they are Figs. 6 and 7) | wrong figure numbers | fixed in the revised manuscript (numbers are now generated) |
| A9 | Highlights say "all 10 532 tests … audited and retained", and the abstract and highlights say quality-aware intervals "equalise coverage". CF = 3 stays under-covered, and only 9 333 tests enter the regression | overstatement | corrected |
| A10 | RQ3 mentions source (laboratory) effects, which are not identifiable. The lab component shown is estimated only on the 70 % subset with an inferred lab | RQ wording promises an unidentifiable quantity | RQ3 reworded |
| A11 | The arXiv identifier of the CCW-Net reference (2611.14407) could not be verified. The reference repository cites NeurIPS 2026 | citation detail | corrected in the reference list (see `reference_audit.csv`) |
| A12 | The MLP and CCW-Net figure panels show seed ensembles, while the tables show per-seed means | already disclosed in the captions | kept, labelled |
| A13 | REML bootstrap uses 100 resamples | interval precision limited | reported; the replicate-ratio interval is new |

No leakage was found:
- geometry, series and random folds are checked by `check_no_leakage` at every split;
- imputation and scaling are fitted on training rows;
- early stopping uses inner folds only;
- the outer test RMSE is never used in a selection.
